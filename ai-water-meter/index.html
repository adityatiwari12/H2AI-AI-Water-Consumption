How it works

No setup beyond installing it once.

1

Install & forget

Add the extension once. It quietly watches for finished responses on the sites you already use.

2

Read, don't intercept

H2AI never touches your prompt data or API keys — it reads the visible response text already on your screen.

3

Estimate & display

A card appears under the response with tokens, cost, and water — and adds to your running session total.

What it shows

Four numbers, every response

H2AI reads the length of the response you just got and estimates what it took to make.

💧

Water, estimated honestly

Scaled from published research on AI inference water use — methodology one tap away.

$

Cost per response

Input and output tokens priced against current API rates for the model you're talking to.

#

Token usage

See input vs. output tokens separately — the number that actually drives cost and footprint.

↻

Session & lifetime totals

A running tally for the conversation you're in, plus a lifetime total across every site.

◈

Per-model accuracy

Haiku and Opus don't cost the same — H2AI detects the model in use and adjusts accordingly.

⌁

100% local

Every calculation happens in your browser. No prompt or response text is ever sent anywhere.

i

These numbers are estimates — and we say so, on every card.

No AI provider publishes real per-query water or energy data. H2AI estimates from response length using published research (including Google's 2025 Gemini inference study) and current public API pricing. Built for awareness, not as an audited metering tool — every card links to the methodology behind its number.
